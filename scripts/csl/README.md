# Bundled CSL style

`chicago-notes-bibliography.csl` is vendored so citation rendering never needs a
network fetch at runtime (FR-8).

| | |
|---|---|

| **Style title** | Chicago Manual of Style 18th edition (notes and bibliography) |
| **Retrieved** | 2026-08-30 |

## Note on the filename

The spec (FR-8, FR-13) names this file `chicago-fullnote-bibliography.csl`.
Upstream renamed the style to `chicago-notes-bibliography.csl`; the old name no
longer resolves in the styles repository. We bundle it under the current
upstream name — see amendment A1 in `docs/REQUIREMENTS.md`.
